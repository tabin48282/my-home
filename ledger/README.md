# 내 가계부 (모바일 웹앱)

카드·통장 이체·주식 투자를 한곳에서 기록하는 가계부입니다. 서버 없이 동작하고 모든 데이터는 **사용 중인 브라우저의 localStorage에만** 저장됩니다. 외부로 전송하지 않습니다.

## 휴대폰에 설치 (GitHub Pages)
1. GitHub 저장소 **Settings > Pages > Build and deployment > Source**를 **GitHub Actions**로 바꿉니다. (한 번만)
2. `main`에 `ledger/` 변경이 반영되면 `.github/workflows/pages.yml`이 자동으로 배포합니다. Actions 탭에서 수동 실행(Run workflow)도 됩니다.
3. 휴대폰에서 `https://tabin48282.github.io/my-home/`을 엽니다.
   - Android(Chrome): 메뉴 ⋮ > **홈 화면에 추가**(또는 앱 설치)
   - iPhone(Safari): 공유 버튼 > **홈 화면에 추가**
4. 한 번 열고 나면 인터넷이 없어도 실행됩니다. 앱을 고친 뒤에는 인터넷이 연결된 상태로 한 번 열어야 새 버전이 받아집니다.

## 실행 (PC에서 확인)
```bash
cd ledger
python3 -m http.server 8000    # 또는 어떤 정적 서버든 가능
# 휴대폰 브라우저에서 http://<PC주소>:8000 접속 → "홈 화면에 추가"
```
- 휴대폰에서 오프라인 앱(서비스 워커)으로 쓰려면 HTTPS 또는 localhost에서 열어야 합니다. GitHub Pages 같은 정적 호스팅에 `ledger/` 폴더를 올려도 됩니다.
- 파일을 그대로 열면(`file://`) 동작은 하지만 서비스 워커는 꺼집니다.

## 기능
| 구분 | 내용 |
|---|---|
| 카드·계좌 | 기본: 신한카드, 산업은행 체크카드, 울산페이카드, 현금, 증권계좌. 설정에서 카드·은행을 얼마든지 추가하고 종류(신용·체크·선불/지역화폐·은행·증권·현금)와 **끝 4자리**를 지정 |
| 카드 자동 구분 | 문자·파일의 카드번호 끝 4자리 → 계정 이름 → 카드사 이름 순으로 추정. 같은 카드사 카드 여러 장도 구분 |
| 입력 | 직접 입력 / CSV·엑셀 업로드 / 카드 승인·입출금 문자 붙여넣기 |
| 가져오기 | 헤더 행·열 자동 탐지(수동 변경 가능), EUC-KR·UTF-8 자동 판별, 이미 있는 내역은 건너뜀(같은 날 같은 결제가 여러 번이면 횟수로 비교), **가져오기 단위 되돌리기** |
| 분류 | 분류 추가·삭제, 키워드 규칙 자동 분류, 내역 수정 시 "같은 가맹점은 앞으로 이 분류로" 체크로 규칙 생성(기존 '기타' 내역에도 적용). `카드대금`·`증권` 같은 계좌 간 이동은 **이체**로 처리해 수입·지출에서 제외 |
| 구분(4가지) | 지출 · 수입 · **저축·투자** · 이체. 저축·투자는 지출에 넣지 않고 결산에서 따로 집계 |
| 기본 분류 | 수입: 급여, 배우자 급여, 상여금, 부업 수입, 금융 수입, 기타수입 / 고정지출: 주거비, 대출, 통신비, 인터넷·TV, 보험료, 차량 유지비, 구독료, 정기결제, 기타 고정비 / 변동지출: 식비, 외식비, 간식·음료, 주류, 생활용품, 교통비, 자동차, 의료비, 의류·미용, 취미·여가, 경조사비, 쇼핑, 기타 / 저축·투자: 예금·적금, 비상금, 주식 투자금, 연금저축, IRP, 기타 투자, 주택대출 추가 상환, 기타 저축 |
| 분류 수정 | 설정에서 분류 이름을 누르면 이름 변경(내역·규칙·목표에 함께 반영), 그룹(고정/변동, 저축/투자/추가 상환), 분류별 월 예산 지정 |
| 월 결산 (홈) | 총수입, 고정·변동·총소비지출, 저축액, 투자금, 대출 추가 상환, 대출 원금 상환액·이자, 잔여자금(수입 − 소비 − 저축·투자), 소비율, 저축·투자율 |
| 예산 초과 알림 | 분류별·전체 예산의 80% 이상이면 주의, 100% 초과면 홈 상단 알림과 저장 시 안내 |
| 월별 비교 | 분류별 지난달 대비 증감액·증감률 |
| 지출 비중 | 분류별 도넛 차트(상위 6개 + 그 외)와 고정·변동 비율 |
| 자산 > 순자산 | 매월 말 자산 6항목·부채 2항목 기록(항목 추가·수정 가능), 총자산·총부채·순자산·전월 대비, 월별 추이 차트, 지난 기록 복사, 투자 평가금액·대출 잔액 자동 채우기 |
| 자산 > 대출 | 대출 종류, 최초 대출금, 잔액, 금리, 상환 방식(원리금균등·원금균등·만기일시), 남은 기간, 상환 목표일. 매월 원금·이자·추가 상환 기록 → 전월·월말 잔액 자동 계산, 가계부 내역에도 자동 반영 |
| 상환 시뮬레이션 | 매월 추가 상환액을 넣으면 상환 기간·완납 예상 월·총 이자를 현재와 비교해 이자 절감액·단축 개월 표시, 목표일까지 필요한 월 추가 상환액 계산 |
| 자산 > 저축 목표 | 연간 목표 금액과 대상 분류를 정하면 달성액·달성률·남은 금액·월 필요 저축액 계산 (여러 개 가능) |
| 요약 | 카드·계좌별 지출, 최근 6개월 소비·저축 추이 |
| 내역 | 카드·구분·분류 필터, 가맹점 검색 |
| 투자 | 주식 매수·매도·배당 기록, 평균단가법 보유 현황, 평가손익·실현손익, 현재가 수동 입력, 보유 수량 초과 매도 차단 |
| 백업 | JSON 백업·복원, 30일 이상 백업하지 않으면 홈에 알림, 내역 CSV 내보내기(엑셀용) |

## 계산 기준
- 잔여자금 = 총수입 − 총소비지출 − 저축·투자(추가 상환 포함). 이체는 제외합니다.
- 대출 원리금을 상환 기록으로 남기면 원금 + 이자가 고정지출 '대출'로, 추가 상환은 저축·투자 '주택대출 추가 상환'으로 내역에 들어갑니다. 같은 금액을 내역에 따로 또 입력하면 이중 집계됩니다.
- 상환 시뮬레이션은 남은 기간 동안 금리가 바뀌지 않고, 추가 상환이 매달 원금에 바로 들어간다고 가정합니다. 은행의 중도상환수수료·일할 이자는 반영하지 않습니다.
- 예전 버전 데이터는 지우지 않습니다. 기존 분류는 그대로 두고 새 분류를 덧붙이며(`주거·통신`·`보험`·`교육`은 고정지출로 표시), 쓰지 않는 분류는 설정에서 지우면 됩니다.

## 사용 시 주의
- 브라우저 데이터를 지우거나 다른 기기로 옮기면 데이터가 사라집니다. **설정 > 백업 파일 저장**으로 주기적으로 백업하세요.
- 카드값을 카드 내역(지출)과 통장 출금(카드대금)에서 둘 다 가져오면 이중 집계되므로, 통장 쪽 `카드대금`은 이체로 분류됩니다. 은행 적요가 다르면 설정에서 분류 규칙을 추가하세요.
- 엑셀(.xls/.xlsx) 업로드는 SheetJS를 cdnjs에서 불러오므로 인터넷 연결이 필요합니다. 연결이 없으면 CSV로 저장해서 올리세요.
- 투자는 원화 기준입니다. 외화 종목은 원화 환산 단가를 직접 입력해야 하고, 시세 자동 조회는 없습니다.

## 개발
- `logic.js`: DOM 없는 순수 로직(파싱·분류·평균단가 계산). Node에서도 `require`로 테스트 가능합니다.
- `app.js`: 화면과 이벤트, `style.css`: 라이트/다크 테마, `sw.js`: 앱 파일 오프라인 캐시.
